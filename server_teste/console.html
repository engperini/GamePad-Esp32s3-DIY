Ajuda

Conexão direta: conecte o aparelho à rede Sophia-Play e abra 192.168.4.1 no navegador completo. A rede não fornece internet.

Roteador: conecte os dois aparelhos à mesma rede local. Abra o IP mostrado acima ou no monitor USB. Redes de convidados com isolamento entre clientes podem impedir o acesso.

Recuperar acesso: se a rede local falhar, a rede Sophia-Play reaparece. Segure BOOT por 5 segundos, com a placa já ligada, para manter a rede própria ativa até reiniciar.

Controle: no jogo servido pelo ESP32, a fonte Automático usa Wi-Fi. Bluetooth continua disponível para os outros jogos. Só um navegador de cada vez recebe o volante via Wi-Fi; feche a outra aba se necessário.

Partições: OTA atualiza a aplicação e o jogo, não a tabela de partições. Mudanças futuras de layout ainda exigem USB. O retorno automático protege falhas de inicialização; não detecta todo defeito de jogabilidade.
